# 강사 준비 — Module 01 실습 환경 체크리스트

kt66(github.com/mrgrit/kt66, 커밋 196bdf5 이후)을 기준으로 한다.

## 1. kt66 기동

```bash
sudo ./kt66.sh up          # 컨테이너 + 호스트 센서(auditd·Sysmon for Linux·osquery·경계 방화벽) + 시각 동기화
```

- `.env` 에 `VIRUSTOTAL_API_KEY` 를 넣으면 실습 55(VirusTotal)가 동작한다. 무료 키는 분당 4회 제한.
- `.env` 의 `WINDOWS_ENABLED=yes` 이면 Windows 평가판 VM 이 함께 설치된다(30~40분). 설치 스크립트가 Wazuh 에이전트·Sysmon·osquery·감사 정책·OpenSSH 를 자동으로 넣는다.
- 확인: 매니저 컨테이너에서 `/var/ossec/bin/agent_control -l` → web·fw·ips·bastion·kt66-host·windows-user 가 Active.

## 2. Windows 만 손으로 할 일 (한 번)

1. 콘솔(`http://<kt66 호스트>:8090/`, 계정 kt66student) 접속
2. Win+R → `windowsdefender://threatsettings` → 아래로 스크롤 → **변조 보호 끔**
3. 관리자 PowerShell: `powershell -ExecutionPolicy Bypass -File C:\Tools\defender-off.ps1`
4. 출력이 `TamperProtected=False RealTimeProtection=False BehaviorMonitor=False` 인지 확인 (재부팅 뒤에도 유지)

> 이 평가판 빌드(2024-03)는 자체 만료일이 지나 "라이선스가 만료되었습니다" 문구가 뜬다. 실습에는 지장이 없었지만, 장시간 켜 두면 재부팅될 수 있다.

## 3. 대시보드 준비

- 아카이브 인덱스 패턴: Dashboard management → Dashboards Management → Index patterns → Create → `wazuh-archives-` 입력(끝의 `*` 는 자동) → Time field `timestamp`. (36·42~45·47·48번)
- 취약점 화면: Threat intelligence → Vulnerability Detection 을 한 번 열어 두면 상태 인덱스 패턴이 만들어진다. (51·52번)

## 4. 공격자 VM (Ubuntu 22.04)

```bash
sudo apt update && sudo apt install -y nmap hydra sqlmap nikto dirb gobuster curl netcat-openbsd python3 python3-requests sshpass
mkdir -p ~/lab
printf '123456\npassword\nadmin\nqwerty\n12345678\nletmein\nwelcome\nccc123\nP@ssw0rd\niloveyou\nabc123\nmonkey\n' > ~/lab/pw.txt
printf 'admin\noracle\ntest\nguest\nbackup\nubuntu\nuser\nftp\npostgres\nmysql\n' > ~/lab/users.txt
# /etc/hosts 에 kt66 웹 이름(*.ccc.com → kt66 호스트 IP) 이 있어야 한다
# 시각: /etc/systemd/timesyncd.conf.d/kt66.conf 에 NTP=<kt66 호스트> → sudo systemctl restart systemd-timesyncd
```

- RDP 실습(31~34)은 공격자 VM → `ssh -p 2202 ccc@<kt66 호스트>` (kt66 내부 공격 컨테이너, xfreerdp·xvfb 설치됨).
- 공격자 VM 저장소(kr.archive)의 freerdp2-x11 은 라이브러리 버전이 맞지 않아 설치되지 않을 수 있다 — 그래서 RDP 는 컨테이너에서 한다.
